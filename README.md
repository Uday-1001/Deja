# ✨ Deja - AI Competitive Programming Mentor

Deja is a highly personalized, AI-powered competitive programming mentor. Instead of giving you the answers outright, Deja analyzes your **past successful code submissions** and guides you through new, unfamiliar problems using the algorithmic intuitions and patterns *you have already mastered*.

It achieves this through a pipeline of dense vector retrieval (FAISS), cross-encoder reranking, and ultra-fast LLM inference (powered by Groq).

## 🚀 Features
* **Personalized Hinting Pipeline**: Routes you dynamically through pedagogical stages (Hint ➡️ Pseudocode ➡️ Reference Code) based on your needs.
* **Semantic Code Retrieval**: Uses `BAAI/bge-large-en-v1.5` embeddings and `bge-reranker-large` to match a new problem statement to the underlying algorithmic structure of your past solutions.
* **Algorithmic Analysis Engine**: Uses Llama 3 (via Groq) to deeply analyze your raw code submissions and extract core techniques, key insights, and time/space complexities.
* **Incremental Learning**: Solve a problem in the app, and instantly ingest it into the vector database so Deja can learn from it for future sessions.
* **Premium UI**: A sleek, glassmorphic Streamlit interface designed for focus and aesthetics.

## 🛠️ Getting Started

### 1. Prerequisites
Ensure you have Python 3.9+ installed.

Clone the repository and install the required dependencies:
```bash
pip install -r requirements.txt
```

### 2. Environment Setup
Create a `.env` file in the root directory and add your Groq API key:
```env
GROQ_API_KEY=your_groq_api_key_here
```

---

## 📂 Preparing Your Data

Deja relies on a JSON file containing your past solved problems (e.g., from LeetCode). 

Downloading your submissions from LeetCode can be done via : https://github.com/jungsu-kwon/Leetcode-Downloader-for-Submissions.git

1. Create a file named `problems.json` in the root directory.
2. Structure your data as a JSON array of objects. 
3. *Note: You can check `sample_problems.json` for a working example.*

Your `problems.json` should follow this structure:
```json
[
  {
    "title_slug": "two-sum",
    "problem_statement": "Given an array of integers nums and an integer target, return indices of the two numbers such that they add up to target...",
    "my_solution_code": "class Solution:\n    def twoSum(self, nums: List[int], target: int) -> List[int]:\n        ...",
    "difficulty": "Easy",
    "topics_tagged": ["Array", "Hash Table"]
  }
]
```
*(Only `title_slug`, `problem_statement`, and `my_solution_code` are strictly required, but difficulty and tags help the LLM).*

## 🏃‍♂️ Running the Pipeline

Once your `problems.json` is ready, run the pipeline in this order:

### Step 1: Analyze Your Solutions
```bash
python analyze.py
```
This script uses Groq to read your code, figure out the actual algorithms you used, and write detailed explanations to `analyzed_problems.json`. *Note: The script has built-in rate-limit handling and checkpoints your progress.*

### Step 2: Build the Vector Database
```bash
python build_vectorstore.py
```
This converts the text generated by the analysis into mathematical vectors and builds a highly optimized `faiss_index`. *(Note: If you skip this, the app will try to build it automatically when you first ingest a new problem).*

### Step 3: Launch the Mentor
```bash
streamlit run app.py
```
Open your browser to the local URL provided in the terminal. Paste a new problem statement into the UI, and Deja will start coaching you!

## 🔒 Privacy Notice
By default, the `.gitignore` is configured to block your `problems.json`, `analyzed_problems.json`, and `history.json` (which contains your personal chat logs with the AI). Your personal LeetCode data remains entirely local to your machine.
